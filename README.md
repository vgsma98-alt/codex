# مشاريع WordPress وTelegram

هذا المستودع يحفظ المشاريع المنجزة في مساحات العمل الحالية، في حزم مستقلة قابلة للتنزيل:

| المشروع | الملف | المحتوى |
| --- | --- | --- |
| وكيل WordPress العام عبر Telegram | [wordpress-telegram-agent-source.zip](wordpress-telegram-agent-source.zip) | خادم Node.js، إضافة WordPress، ملفات EasyPanel وتعليمات التشغيل |
| مطعم BLJLUX | [bljlux-restaurant-source.zip](bljlux-restaurant-source.zip) | قالب المطعم، الصور، إضافة إدارة المحتوى ودليل التثبيت |
| تأجير السيارات Atlas Drive Maroc | [atlas-drive-delivery.zip](atlas-drive-delivery.zip) | القالب، صور السيارات، إضافة WordPress، وكيل Telegram ودليل التثبيت |
| تطبيق LEADBOYACH | [leadboyach-source.zip](leadboyach-source.zip) | تطبيق البحث عن العملاء، الواجهات، إعدادات النشر، ودليل التشغيل |
| إضافة رواق أفلييت | [riwaq-affiliate-source.zip](riwaq-affiliate-source.zip) | شيفرة إضافة WordPress، الحزمة الجاهزة، ودليل الاستخدام |

نزّل الحزمة المطلوبة وفك ضغطها على أي حاسوب. لا تتضمن الحزم كلمات مرور أو رموز بوت أو بيانات قواعد WordPress الحية. احتفظ لكل موقع بملف أسرار منفصل خارج GitHub.
