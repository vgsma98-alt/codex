# Project handoff for AI agents

This repository contains five independent project archives. Each project has a guide under `guides/<project>/README.md` for both the owner and AI coding agents. Read that guide before editing its archive.

- WordPress Telegram agent: `wordpress-telegram-agent-source.zip` — `guides/wordpress-telegram-agent/README.md`
- BLJLUX restaurant: `bljlux-restaurant-source.zip` — `guides/bljlux-restaurant/README.md`
- Atlas Drive Maroc: `atlas-drive-delivery.zip` — `guides/atlas-drive/README.md`
- LEADBOYACH: `leadboyach-source.zip` — `guides/leadboyach/README.md`
- Riwaq Affiliate: `riwaq-affiliate-source.zip` — `guides/riwaq-affiliate/README.md`

Extract only the relevant archive into its own working directory. Never edit a ZIP as source. Do not delete existing files without the owner’s approval. Do not commit credentials, tokens, live databases, uploaded customer media, or private customer data. These are source packages, not complete production backups.
