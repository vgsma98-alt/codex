# رواق أفلييت — دليل المستخدم والوكيل

[تنزيل المشروع](../../riwaq-affiliate-source.zip)

إضافة WordPress لعرض منتجات الأفلييت من الإدخال اليدوي أو CSV، مع أدوات لمراجعة الانتقال من بعض أكواد AAWP. شيفرة الإضافة في `riwaq-affiliate/`، وحزمة التثبيت `riwaq-affiliate-2.5.1.zip`، والدليل المفصل `README.md`.

## التثبيت والاستخدام

1. خذ نسخة احتياطية من WordPress وجرّب الإضافة على موقع اختبار.
2. ارفع `riwaq-affiliate-2.5.1.zip` من **إضافات ← أضف إضافة ← رفع إضافة** ثم فعّله.
3. اضبط المتجر ومعرّف الشريك واللغة. أضف المنتجات يدوياً أو عبر CSV؛ يوجد مثال في `riwaq-affiliate/sample-products.csv`.
4. راجع الأسعار والصور والروابط قبل النشر. عند الانتقال من AAWP، استخدم أدوات الفحص واقرأ حدود التوافق في `README.md`.

## للمطور أو نموذج الذكاء الاصطناعي

افتح الحزمة المفكوكة في Codex. نقطة البدء `riwaq-affiliate/riwaq-affiliate.php`، وفئات PHP في `riwaq-affiliate/includes/`، وملفات التصميم في `assets/`. افحص PHP واختبر عرض المنتجات والاستيراد والاختصارات وأكواد AAWP الممثلة على موقع تجريبي، ثم أنشئ حزمة ZIP جديدة بعد الاختبار. لا تخترع سعراً أو توافراً أو تقييماً للمنتجات.

لا تحذف ملفات أو تهاجر بيانات الإنتاج دون موافقة المالك ونسخة احتياطية. قاعدة WordPress الحية غير موجودة في هذه الحزمة. احتفظ بأسرار الخدمات وبيانات العملاء خارج GitHub.
