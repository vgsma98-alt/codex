# LEADBOYACH — دليل المستخدم والوكيل

[تنزيل المشروع](../../leadboyach-source.zip)

تطبيق للبحث عن العملاء المحتملين وإدارة مسار المبيعات. تشمل الحزمة شيفرة التطبيق و`README.md` للاستخدام و`deploy/VPS-GUIDE-AR.md` للنشر. لا تشمل قاعدة Supabase الحية أو بيانات العملاء أو سير عمل n8n.

## للمستخدم

افتح `README.md` لمعرفة التسجيل والبحث ومتابعة العملاء والتصدير والاشتراكات. في النشر الصحيح يكون التطبيق على `/`، والموقع التعريفي على `/landing`، وصفحة الاتصال على `/contact`.

## للمطور أو نموذج الذكاء الاصطناعي

فك الحزمة وافتحها في Codex. افحص `package.json` للأوامر الدقيقة. المشروع يتطلب Node.js 22.13 أو أحدث و`pnpm` وفق الدليل. الصفحات في `app/`، ومسارات API في `app/api/`، والمكونات في `components/`. ضع إعدادات Supabase وWebhook في متغيرات البيئة مسترشداً بـ`.env.example` و`deploy/vps.env.example`، ثم شغّل فحوص lint/type/build المناسبة. للنشر اتبع `deploy/VPS-GUIDE-AR.md`؛ تتوفر ملفات `Dockerfile` و`compose.yaml`. حافظ على العربية والفرنسية والإنجليزية واتجاه RTL/LTR.

لا تحذف ملفات أو بيانات دون موافقة المالك. لا تفترض أن الحزمة تنقل قاعدة Supabase أو n8n، ولا تطبق ترحيلات على الإنتاج اعتماداً على الحزمة وحدها. لا تضع مفاتيح الخدمة أو بيانات العملاء أو روابط Webhook السرية في المستودع.
