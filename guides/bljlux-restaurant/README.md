# BLJLUX — دليل المستخدم والوكيل

[تنزيل المشروع](../../bljlux-restaurant-source.zip)

هذه حزمة موقع المطعم. تضم قالب WordPress في `bljlux-ai-restaurant/` وإضافة إدارة المحتوى في `bljlux-content-agent/` و`INSTALL_AR.md`. الصور التجريبية ضمن القالب. لا تشمل قاعدة البيانات الحية أو الحجوزات أو الصور التي رفعها الزبائن.

## التثبيت

1. ثبّت WordPress على استضافة HTTPS. اضغط مجلد القالب وحده إلى ZIP وارفعه من **المظهر ← قوالب** ثم فعّله.
2. اضغط مجلد الإضافة وحده إلى ZIP وارفعه من **إضافات ← أضف إضافة ← رفع إضافة** ثم فعّله.
3. افحص الصفحة الرئيسية والقائمة والحجز والاتصال بالفرنسية والعربية. راجع `INSTALL_AR.md`؛ قد يستخدم أسماء مجلدات قديمة، بينما المساران الفعليان مذكوران أعلاه.
4. وكيل Telegram خدمة منفصلة: استخدم حزمة الوكيل العام وأنشئ بوتاً وسراً خاصين بالمطعم.

## للذكاء الاصطناعي والمطور

افتح الحزمة المفكوكة في Codex. أهم ملفات القالب: `bljlux-ai-restaurant/front-page.php` و`functions.php` و`style.css` و`assets/slider.js`. نقطة بدء الإضافة `bljlux-content-agent/bljlux-content-agent.php`. حافظ على اتجاه RTL للعربية وLTR للفرنسية، واختبر العرض على الهاتف والحاسوب وفحص PHP قبل النشر. تعديل صورة داخل الحزمة لا يضمن تغيير صورة مخزنة في WordPress؛ افحص الإعدادات وقاعدة البيانات والوسائط الحية.

لا تحذف ملفات قائمة دون موافقة المالك. احتفظ بنسخة من قاعدة WordPress و`wp-content/uploads` قبل تغييرات الإنتاج. لا ترفع رموز البوت أو أسرار الموقع إلى GitHub.
